## 🎬 Gen·AI Studio (GenAIHub)

A desktop app (macOS, Electron + Node) that brings every generative model I use in production
into one place, with a library, projects and real per-job cost tracking.

**FLUX (Black Forest Labs) is fully integrated:**
- **FLUX 3 Video:** text/image → video, keyframes, extend, draft → enhance in HD/FHD
- **FLUX.2:** image generation
- **FLUX Tools:** video upscale, erase (with masks from the built-in image editor), outpainting, deblur, virtual try-on
- Automatic retries under load, recovery of interrupted jobs, billing from reported credits

**Also:** OpenAI GPT-Image, Google Gemini, Seedance/Seedream, Kling, Wan, ElevenLabs

**Modules**
- **Canvas:** node editor that wires models and tools into pipelines
- **STORY:** script → scenes → images → videos, with consistent characters, locations and series rules
- **Image editor:** marks, masks and crops to prepare inputs for the models
- **3D scene editor:** camera and blocking in three.js, exported as a reference video
- **Claude integration (MCP):** the app can be driven by an AI agent
